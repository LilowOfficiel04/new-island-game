# NEW ISLAND - L'Île de la Tentation

Jeu narratif interactif créé en HTML/CSS/JavaScript.

## Description

Plonge dans une aventure de séduction et de trahison dans deux villas rivales : **Villa Tempuras** et **Villa Lagoon**.
Choisis ton camp, suis les chapitres, et prends des décisions qui modifient ton destin.

## Fichiers principaux

- `index.html` : page principale du jeu
- `Fond_menu.PNG` : fond du menu d'accueil
- `Tempuras.PNG` : fond de l'histoire Tempuras
- `Lagoon.PNG` : fond de l'histoire Lagoon
- `nomenclature_assets.md` : notes sur les assets
- `preview/` : dossier de prévisualisation

## Comment jouer

1. Ouvre `index.html` dans un navigateur web.
2. Clique sur **Jouer**.
3. Choisis la villa qui te correspond.
4. Suis les chapitres et fais des choix.

## Publier sur GitHub Pages

1. Sur GitHub, va dans `Settings` du dépôt.
2. Dans la section **Pages**, choisis la branche `main`.
3. Sélectionne le dossier `/root` ou `/(root)`.
4. Clique sur **Save**.
5. Ton site sera disponible à une URL du type :
   `https://LilowOfficiel04.github.io/new-island-game`
